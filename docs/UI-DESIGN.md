# UI 设计规范 (UI Design Specification)

## 1. 产品性格 (Product Personality)

本应用定位年轻、趣味、色彩丰富。贯穿整个体验采用猫咪陪伴 IP 角色，包括引导、待确认队列、报表、权限及确认流程。

UI 可以可爱，但在敏感时刻必须保持严肃、清晰、无歧义：
- 资金变动。
- 隐私权限。
- AI 数据上传。
- 账号注销。
- 本机数据删除。
- 备份与恢复。
- 账户账本同步与冲突解决。

## 2. 导航架构 (Navigation)

主页底部导航目的地：
- 待确认 (Review)。
- 账本 (Ledger)。
- 报表 (Reports)。
- 我的 (Profile)。

四个导航选项卡插图跨越导航栏顶边，并使用表面颜色的轮廓。使用 52 dp 的艺术图和 15 sp 的标签。凹陷的中央切口容纳现有的带柔和阴影的紫色圆形“添加”按钮；“添加”按钮不是第五个可选择的导航目的地。二级目的地页面隐藏底部导航并透出明确的返回主页操作。

待确认队列在导航顺序中排在第一位。自动记账开关、运行状态、无障碍授权入口、自启动与电源策略状态/设置入口位于“我的 → 自动记账”。

### 2.1 主页总览

主页定位为当前账本的财务与待办总览，不重复展示底部导航入口宫格：
- 内容使用单一纵向滚动容器，最大宽度 880dp；小于 610dp 时水平留白 20dp，610dp 及以上为 32dp。
- Header 显示“主页”、当前账本名称；存在多个账本时可展开选择，只有一个账本时显示静态名称。本机数据替换期间禁用切换。
- 月度概览卡显示当前账本中最新可分析月份的结余、支出和收入，并明确标注真实年月；点击进入完整报表。无可分析收支时显示已有报表空状态插画。
- “需要处理”只在存在待确认记录、已开启自动记账的授权/运行/电源问题，或已开启账户同步的冲突/错误时出现。同步错误仅显示稳定提示，不显示 Provider 原始错误正文；正常状态和普通待上传数量不占用主页。
- “最近账目”按交易时间倒序展示三笔未删除账目，字段为分类插画、商户、分类、时间和带方向的金额；点击进入既有账目编辑器，“查看全部”进入账本。目标在点击后被并发删除时回到账本列表并提示。
- 无账目时使用已有账本空状态插画，不增加第二个“记一笔”按钮，继续使用底部中央添加按钮。

## 3. 待确认队列 (Review Queue)

主界面构成：
- 内容宽度上限为 880dp；手机端水平留白 20dp，600dp 及以上窗口使用 32dp。
- 顶部 Header 使用 `待确认` 主标题和 `确认后记入「<当前账本名>」` 说明，右侧保留已忽略记录入口与返回主页操作。
- 一张 24dp 圆角的品牌色状态汇总卡片，使用待确认插画并突出待处理总数。
- 一个待确认记录列表。

顶部汇总卡片：
- 待确认总额。
- 疑似重复笔数。
- 今日待确认笔数。

待确认列表：
- `待确认记录` 分组标题下显示左右滑动提示，并包含每一个待确认条目。
- 条目使用 20dp 圆角、轻阴影和弱描边；无数据时使用同样的分组卡片与待确认空状态插画。
- 每一行上置信度状态保持可见。

默认排序规则：
- 疑似重复与低置信度优先排列。
- 随后按捕获时间倒序排列。

列表项展示内容：
- 金额。
- 商家/标题。
- 建议分类。
- 来源。
- 捕获原因。
- 置信度状态。

滑动操作 (Swipe Actions)：
- 向右滑动：确认入账。
- 向左滑动：忽略。
- 仅当行滑动超过其宽度的 约 40% 时方可触发处理；较短的慢速或快速滑动松开后复位而不触发操作。
- 两种滑动均展示带“撤销”选项的 Snackbar。

已忽略条目：
- 可在已忽略列表中保留 30 天并支持恢复。

## 4. 待确认条目详情页 (Pending Entry Detail)

页面布局：
- 顶部优先展示解析结果汇总。
- 接下来展示可编辑字段。
- 证据区域默认折叠。
- 底部固定操作栏。

可编辑字段：
- 金额。
- 时间。
- 交易类型。
- 分类。
- 资金账户。
- 商户（可选），最多显示两行输入内容。
- 备注。
- 资金流向仅提供“支出”和“收入”，不提供“不计收支”选项。

证据区域：
- 来源。
- 捕获时间。
- 解析字段。
- 新自动候选只显示规范化解析字段，不显示原始页面文字；历史条目仍按已有持久化证据兼容展示。

操作按钮：
- 确认按钮上方显示：“确认后记入「<当前账本名>」”。
- 确认入账。
- 忽略。

## 5. 自动记账 (Automatic Bookkeeping)

入口位于“我的 → 自动记账”，页面只包含：
- 总开关，默认关闭。
- 当前状态：`已关闭`、`等待无障碍授权`、`监听服务未运行`、`正在监听`；监听状态只反映当前进程内无障碍 Service 的实际生命周期，未授权时不得显示运行中。
- 后台运行保障使用四个紧凑单行，依次显示图标、名称、状态和设置按钮：无障碍授权、自启动、电源策略、通知设置。
- 无障碍授权显示“已授权 / 未授权”并提供系统无障碍设置跳转；监听服务未运行不自动关闭总开关。
- 自启动显示“请确认”并提供厂商设置跳转；Android 不提供统一、可靠的自启动状态查询接口，不伪报已开启。电源策略显示公开 API 可判断的系统电池优化“已豁免 / 未豁免 / 不可用”，从系统页返回后刷新；厂商“无限制”等附加策略仍以系统页为准。
- 电源策略优先打开本 App 电池详情，自启动在 Xiaomi/HyperOS 优先打开系统安全中心；都保留标准应用详情/系统设置回退，不直接请求电池优化白名单。

页面不提供隐私说明、平台选择、手动补录、来源启动、进度步骤或 OCR 说明。

## 6. 账本 (Ledger)

Header 区域：
- 使用“账本”作为页面标题，当前账本名称作为说明；内容宽度上限为 880dp。
- Overflow 溢出菜单按顺序排列“账本管理”、“资金账户”和“最近删除”。

顶部月度汇总：
- 使用 24dp 圆角品牌色插画卡片，以结余/净额作为主值，月度支出与月度收入作为两个辅助指标。

主要操作：
- 主页底部导航中的抬高中央操作按钮打开手动录入表单。
- 账本页面不通过本地悬浮按钮重复此操作。
- 手动录入不在待确认队列页面中重复出现。

列表展示：
- 一次展示一个可用月份，配有 `上一月` 与 `下一月` 切换控件；包含条目的首月之前或末月之后禁用导航。
- 标题、汇总、搜索、筛选、月份与账目共同位于可滚动内容中，保证小屏和大字体下全部功能可达；账目仍保持单列扫描顺序并恢复离开前的列表位置。
- 列表行使用 20dp 圆角、轻阴影和弱描边，字段包括商家/标题、分类、时间、金额、来源标识。
- 点击列表行直接打开共享的账本条目编辑器。
- 列表、汇总、搜索及筛选均仅针对当前账本。

账本管理：
- 罗列每个账本及其名称、条目数量和当前标识。
- 选择账本会持久化该选择并返回该账本的账面。
- 新建账本会去除名称前后空格，拒绝空白或重复名称，并立即选中新建的账本。
- 删除需要二次确认。包含活动或最近删除条目的账本，或最后一个剩余账本，显示具体的阻断原因而非直接删除。
- 本版本不透出账本重命名或移动条目操作。

资金账户：
- 罗列跨账本共享的所有资金账户，并提供新建、编辑和删除操作。
- 表单包含必填名称和可选的微信/支付宝支付来源。
- 拒绝在同一支付来源下存在规范化后的相同名称；允许不同支付来源下使用相同名称。
- 编辑保留现有账户标识，不重写历史账本条目的支付来源。
- 删除需要二次确认。当存在引用时，保留该账户并展示活动/已删除账本条目、待确认条目及已忽略条目的引用计数。
- 资金账户仅从独立的“资金账户”页面创建；不从账本条目的创建或编辑中透出新建入口。

账本条目编辑器：
- 优先展示当前交易字段。
- 将资金流向与交易类型、金额分开独立展示。
- 资金流向仅提供“支出”和“收入”，不提供“不计收支”选项。
- 商户字段统一显示“商户（可选）”，最多显示两行输入内容，长文本可将光标移回开头继续编辑。
- 货币显示为 CNY，首版本不提供货币选择器。
- 金额输入框仅接受至多两位小数的正数；资金流向控制展示的正负号。
- 日期时间选择器不允许选择晚于当前设备时间的值。
- 资金账户选择器罗列已有账户；不提供内嵌创建账户功能。
- 分类选择器使用已有分类及“未分类”，无内嵌创建分类操作。
- 条目来源、生命周期时间戳、原始捕获来源、原始待确认条目 ID 及捕获证据保持持久化，但在当前账本 UI 中不组装展示。
- 手动创建与编辑复用相同的交易表单。
- 在用户点击“保存”之前，表单修改保持在本地。
- 带未保存修改返回时，弹窗询问放弃修改或继续编辑。
- 编辑器包含“删除”按钮；二次确认明确告知条目将移至“最近删除”保留 30 天。
- 删除后返回账本，并展示“已移至最近删除”带撤销选项的 Snackbar。

最近删除：
- 列表作用域限定为当前账本。
- 显示删除时间及每个条目剩余的保留天数。
- 每个条目提供“恢复”与“永久删除”操作。
- 永久删除需要二次确认，明确告知该条目无法恢复。
- 超过 30 天后条目自动彻底清除。

搜索与筛选：
- “搜索商户或备注”输入框与紧凑的“筛选”按钮位于同一行，搜索框占据主要宽度且两者垂直居中。
- 点击“筛选”按钮展开或收起筛选面板。
- 筛选面板使用 20dp 圆角分组卡；字段为来源、分类、交易类型，720dp 及以上内容宽度横向排列，否则纵向排列。

## 7. 报表 (Reports)

主界面：
- 内容宽度上限为 880dp；标题使用“报表”，说明为“当前账本收支分析”。
- 将所有总额、分类占比和现金流查询的作用域限定在当前账本。
- 设 `x` 为当前账本中至少包含一笔可报表收入或支出条目的最新月份；中性条目不确立 `x`。
- 顶部使用 24dp 圆角品牌色插画卡片，以 `x` 月结余为主值，收入与支出总额作为辅助指标。
- 将面板 A（`x` 月支出分类占比）排在面板 B（七个月现金流表格）之前。
- 概览使用单一纵向滚动容器；环形图、分类排行和七个月现金流分别使用 20dp 圆角分组卡片。

面板 A — 支出分类占比：
- 使用 Compose `Canvas` 绘制手绘风手绘环形图 (Donut)。
- 仅包含 `x` 月的流出/支出条目。按支出金额对分类排序，保留前四个，将剩余分类合并为“其他”。
- 环形图配有图例，显示分类名称和一位小数百分比。保留现有的排行榜作为只读列表，显示分类名称和金额；颜色作为装饰性强化，绝不作为识别分段的唯一方式。
- 520dp 以下内容宽度将环形图与图例上下排列，较宽窗口并排展示；分类排行首页只预览前三项，“更多”进入完整排行并恢复滚动位置。
- 当 `x` 月有收入但无支出时，将环形图和排行榜替换为“本月暂无支出分类”，同时保持收入概览可见。

面板 B — 七个月现金流：
- 将包含窗口 `[x-3, x+3]` 显示为按月份排序的月份、支出和收入列。
- 用 0 补全该窗口中缺失的月份，通过滚动保持所有七个月份行可用，使用淡紫色背景高亮第 `x` 行，支出使用珊瑚色，收入使用青绿色。
- 不提供分类选择，也不保留以前特定于分类的六个月趋势图。

报表级无数据状态：
- 若当前账本没有可报表的收入或支出条目，则不存在 `x`；使用报表空状态插画并显示“当前账本暂无可分析的收支”，而非概览总额或填零的报表内容。
- 中性条目排除在收入、支出、分类占比和现金流计算之外。

## 8. 我的 (Profile)

顶部区域：
- 紧凑的账号状态卡片链接至“账号管理”。
- 本地模式显示：“本地模式 · 账本存储在本机”。
- 已登录模式显示主标识（手机号和邮箱脱敏）及账号状态。
- Profile 概览不添加头像、昵称、签名或其它个人资料字段；头像、昵称和公开账号 ID 在账号管理页展示。

二级入口列表（按顺序）：
1. 账号管理。
2. 自动记账。
3. 分类规则。
4. 数据与备份。
5. 合规与隐私（Debug 下方另有诊断日志）。

通知设置入口位于“自动记账”的后台运行保障区，沿用同组行布局，仅显示图标、名称、系统通知状态（已允许／未允许）和最右侧“设置”。状态表示系统总授权，不表示各类提醒开关；从系统设置返回时刷新。点击打开现有通知设置页，页面返回和系统返回均回到自动记账页。说明精简，保留关键触发条件与系统限制。

通知设置提供“新增待确认提醒”、系统通知授权状态与跳转、“锁屏隐藏交易详情”（默认开启）。权限拒绝时明确说明仍会正常识别并保存待确认。系统通知包含金额、商户、建议分类、识别时间及来源；多笔分组，点击单笔进入现有待确认编辑页，数据加载完成后才判断目标是否已处理。通知不提供一键直接入账操作。

通知设置另有独立的“自动记账中断提醒”（默认开启）和“待确认积压提醒”（默认关闭）。中断持续 30 秒复核后提醒，点击进入自动记账页；同一故障只提醒一次，恢复稳定五秒后允许下次故障提醒。积压达到 10 笔或最早识别超过 48 小时后由约每小时的后台检查提醒，最多每 24 小时一次，队列未变不重复；点击进入待确认列表，仅显示数量。页面说明后台检查可能延迟、强制停止时无法保证中断提醒；各通知渠道也可在系统设置单独关闭。总的系统授权状态与应用内三个提醒开关分别展示。

每个概览行仅包含一个状态摘要和一个导航指示器。绝对不包含开关、权限按钮或备份密码输入框。选择某行会打开带标题和返回操作的完整二级页面。目的地页面和二级页面隐藏底部导航；从 Profile 二级页面返回会回到 Profile 概览，从 Profile 概览返回会回到主页。

账号管理：
- 在本地模式下，解释当前状态并提供登录或注册入口。
- 已登录时，展示账号 Profile 头像、昵称、主标识，以及用户名、脱敏手机号、脱敏邮箱和对应登录标签；可修改昵称，并可通过“拍照”或“从相册选择”修改头像。上传进行中禁用重复操作，失败原因显示在头像行附近。
- 公开账号 UUID 使用“前 8 位 + `****` + 后 4 位”的短格式展示，复制按钮始终可见并复制完整 UUID；离线旧 Session 尚无 UUID 时显示“暂不可用”，不得显示或复制 Session Token。
- 缺失手机号/邮箱时提供补绑；已有手机号/邮箱时提供经对应验证码确认的换绑。未配置 AppID 时继续隐藏微信入口。
- 合并确认展示当前与来源账号，明确“当前配置优先、来源 AI 日志删除、本机账本不变、来源云账号删除且不可自动撤销”，并要求输入“合并账号”。
- 解绑微信要求选择密码或验证码验证；同时绑定手机号和邮箱时可选择“手机验证码”或“邮箱验证码”，并明确解绑后仍保留已绑定账号登录方式。纯微信账号不显示可执行的解绑入口。
- 正常退出登录与视觉隔离的账号注销危险区域保持独立。
- 退出登录会保留所有本地账本，而账号注销遵循其独立的冷静期流程。
- 可见返回与系统返回按同一层级导航：找回密码返回登录；登录、注册、本地模式说明和合规材料返回账号落地页；从“账号管理”打开的账号落地页返回“账号管理”。

分类规则：
- 页面沿用“我的”二级页面视觉：标题与说明在左、文字返回操作在右，内容宽度上限为 880dp；顶部使用分类规则插画摘要卡，智能辅助与本地规则分别使用 20dp 圆角分组卡片。
- 在每种账号状态下保持本地规则管理可用。
- 规则编辑仅包含“商户包含”和“分类”；商户支持用英文逗号分隔多个名称，分类必须从当前已有分类中选择。
- 规则列表不按交易类型筛选；支付来源和交易类型由交易识别链路决定，不在分类规则中配置。
- 在本地模式下，将云端 AI 描述为需要登录，不提供开启控件。
- AI 开启后，增强上下文作为单独的选项显示。关闭 AI 也会关闭增强上下文；重新开启 AI 将从最小字段开始。

数据与备份：
- 将当前账本 CSV 导出和所有账本加密备份导出/导入保留在常规区域；其描述必须明确不同的作用域。
- 将“本机数据删除”放在底部的独立危险区域，保留备份提醒和文本输入确认。
- 导入首先在不更改本地数据的情况下校验备份和口令；只有第二次显式确认才允许替换本地快照。

合规与隐私：
- 分别展示“隐私政策”、“个人信息收集清单”、“第三方服务清单”和“权限使用说明”的独立入口；每个入口打开各自的页面，并在本地模式下保持可用。
- Debug 构建在“我的”总览中将“诊断日志”作为紧随“合规与隐私”的同级入口；Release 不显示该入口或页面。商店审核材料、设备矩阵、权限留存检查和质量指标仅保留在 Debug 构建的开发者工具中。

## 9. 登录、注册与找回密码

登录/注册首屏：
- 猫咪陪伴形象。
- 价值主张说明。
- “微信登录/注册”位于统一账号登录和创建账号之前；无 AppID 时隐藏。
- 登录与注册页使用“用户名 / 邮箱 / 手机号”统一输入框，底部提供相同微信入口。
- 本地模式入口。

注册流程：
- 用户名注册直接设置密码，验证码行完全隐藏且不得请求或提交验证码。
- 邮箱和手机号注册分别使用 SMTP 邮件验证码和短信验证码；验证码输入框与获取按钮同一行，宽度约 2:1、间距 8dp。
- 标识变化时清空旧验证码和倒计时，非法邮箱或纯数字输入不得回退为用户名。
- 未绑定微信授权后先展示头像和昵称，可创建纯微信账号，或选择密码/验证码绑定已有账号。
- 纯微信账号可新增未注册手机号或邮箱并设置密码；密码账号之间的标识冲突只显示阻止信息，不进入合并。

本地模式：
- 入口清晰可见。
- 一次性弹窗说明：本地记账可用，但云端 AI、已注册设备配置及账户同步需要登录。

账户同步：
- “数据与备份”显示启用状态、最近成功时间、待上传数量、立即同步、错误重试和冲突；Profile 只显示简短状态。
- 首次启用列出同步范围、服务端可读存储、HTTPS 要求和账号注销影响；本机与云端都非空时显示数量并要求确认合并。
- 局域网 HTTP 测试模式持续显示未加密风险。冲突逐条对比本机与云端版本，并允许保留其一；提交前再次校验云端版本。
- 冲突区只显示需要用户决策的真实编辑。全新安装后未修改的系统分类和初始分类规则采用云端版本，不因安装时间或内置模板版本差异显示冲突。
- 换账号时，原账号仍有待上传数据则阻止切换；确认后仅替换正式同步范围，待确认、已忽略和设备设置保留。

协议同意：
- 登录、注册及本地模式均要求勾选同意用户协议和隐私政策。
- 未勾选协议时点击微信入口不得创建或调用 OpenSDK，只显示既有协议提示。

忘记密码：
- 入口位于密码输入页底部。
- 流程：已绑定手机号或邮箱确认 -> 对应渠道验证码 -> 设置新密码；纯用户名且未绑定联系方式时不可自助找回。

## 10. 账号表单反馈与文案 (Account Form Feedback)

文案基调：
- 友好、直截了当。
- 明确说明出了什么问题以及如何解决。
- 不要在账号、安全、隐私或支付错误中过度使用猫咪梗。

位置提示：
- 字段错误出现在相关输入框下方。
- 全局错误使用顶部或底部消息条提示。

固定文案规范：
- 手机号格式："请输入 11 位手机号"。
- 用户名格式："用户名需 4-20 位，以字母开头，仅包含字母、数字和下划线"。
- 邮箱格式："请输入有效的邮箱地址"。
- 密码规则："密码需 8-32 位，包含大小写字母、数字和符号"。
- 验证码错误："验证码不正确，请重新输入"。
- 验证码过期："验证码已过期，请重新获取"。
- 验证码频繁："获取太频繁，请稍后再试"。
- 密码/登录失败："账号或密码不正确"。
- 账号临时锁定："尝试次数过多，请稍后再试，或使用手机号或邮箱找回密码"。
- 网络失败："网络连接失败，请检查后重试"。
- 协议未勾选："请先阅读并同意用户协议和隐私政策"。
- 验证码发送失败："验证码发送失败，请稍后重试"。
- 标识已注册："该账号标识已注册，请直接登录"。
- 标识未注册："该账号标识尚未注册，请先创建账号"。
- 两次密码不一致："两次输入的密码不一致"。

## 11. 诊断日志 (Diagnostic Logs)

- Debug 在“我的”总览的“合规与隐私”下方直接显示“诊断日志”，点击进入独立页面；Release 始终不显示该入口或页面。原“开发者工具”仍仅 Debug 可见。
- Debug 页面明确列出支付宝完整正文、批次元数据、排障用途、10 MiB 上限、超过上限才轮转、设备内 UTF-8 明文 `.log`、关闭/清空方式和明文导出风险；认证秘密仍在写入前清除。
- 列表默认加载最新 1000 条并直接显示明文单行内容。每个自动记账实际采集批次一条，展示秒级时间、触发事件及各自次数、实际节点数、正文和新增成功/未新增/失败原因；支付宝显示完整采集正文，非支付宝正文为空。支持级别、组件及统一文本筛选。
- 诊断页从进入到离开全程启用 `FLAG_SECURE`，直接显示正文，不提供敏感内容遮罩或二次显示确认。
- 操作包括启停、刷新、无口令“明文导出 .log”和二次确认清空。导出期间按钮禁用并显示进度，完成或失败使用当前可见弹窗反馈，成功信息包含准确文件名。关闭不删除历史；清空删除现行 `.log`、遗留 `.aadlog` 和遗留诊断密钥，旧 `.aadlog` 不读取、不迁移。
- 导出成功后提示 Downloads 中的 UTF-8 明文 `.log` 不会随本机数据删除，需要用户自行保管或删除；账本备份仍按“数据与备份”页面使用口令加密。

## 13. 视觉系统 (Visual System)

色彩语义：
- 支出：暖色调（如珊瑚红/橙）。
- 收入：绿色。
- 风险/权限问题：红色。
- 品牌主色：活泼的蓝色或紫色。

图表风格：
- 手绘插画风与趣味性。
- 必须保持数值标签、总额及对比关系清晰易读。

猫咪陪伴形象：
- 2D 插画。
- 动态轻量微动画。
- 可出现在所有体验流程中。
- 绝对不得替代清晰的授权同意或警告文案。
